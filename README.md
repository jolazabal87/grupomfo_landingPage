# Grupo MFO 2.0 — Premium React SPA

Landing institucional de Grupo MFO 2.0 desarrollada en React + Vite.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir la URL que indique Vite, normalmente http://localhost:5173

## Build de producción

```bash
npm run build
```

La carpeta `dist/` contiene la versión lista para publicar.
